# Adaptive Water Purifier — Project Website (External View)

## Live Website
https://dyhuanchula.github.io/S26-CBE3300B/

This site documents our semester-long design project for **S26-CBE3300B**: a continuous water purifier that recirculates water through a particulate filter and activated carbon until onboard sensors indicate it meets a “clean” threshold, then dispenses the treated water. The system also reports pH and automatically refills the chamber to continue operation.
