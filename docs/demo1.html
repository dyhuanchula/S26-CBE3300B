Application of ChemE Principles

Solid–Liquid Separation (Filtration)

Suspended particulates (diatomaceous earth, ~5–50 µm) are removed by depth or surface filtration. The pressure drop across the filter bed (Darcy's law, ΔP = μQL/kA) governs flux; a clogged or over-sized cartridge severely limits throughput.

Mass Transfer — Turbidity as Surrogate

Turbidity (NTU) correlates with suspended-solids concentration via Beer–Lambert scattering. The sensor measures transmitted/scattered light intensity; calibration maps voltage to NTU so the controller can infer effluent quality in real time.

Residence Time & Flow Rate

Effective clarification requires sufficient contact time inside the filter (τ = V/Q). The peristaltic pump sets Q; the filter volume V and pressure differential together determine whether τ is long enough for target particle removal.

Feedback Control Loop

The designed control strategy reads turbidity, compares to a setpoint, and actuates valves to recirculate or pass water downstream — a classic proportional on/off control analogous to a CSTR with recycle.

Current Performance Limitation The oversized filter cartridge means the housing does not seal properly, allowing bypass flow around the media. This artificially inflates apparent turbidity removal efficiency and makes calibration data unreliable until the correctly-sized cartridge arrives.

Test Material: Milk → Diatomaceous Earth

Why we switched — Milk particle size is too small to meaningfully test the filter, and milk goes bad. Diatomaceous earth (DE) produces a more reproducible, inorganic particulate suspension with well-characterised settling behaviour, making it a better calibration standard.
  • Settling test: DE suspensions were photographed to show visible differences in turbidity and how quickly the suspension settles over time.
  • Implication: A new turbidity calibration curve must be generated using DE standards before closed-loop testing can proceed.

Project Management + Next Steps

Action items before Demo 2, in rough priority order.

  • Blocker Wait for correctly-sized filter cartridge — system cannot be sealed or performance-tested until the replacement arrives. Track shipping and test fit immediately on receipt.
  • Sensor Redo turbidity calibration with diatomaceous earth — prepare DE standards at known concentrations (e.g. 0, 5, 10, 25, 50, 100 NTU equivalents), record sensor voltage, generate a new calibration curve, and update firmware constants.
  • Software Fix serial monitor conflict during pump operation — investigate shared-ground / power-rail noise causing USB disconnect. Consider using SD card logging or Bluetooth serial as a workaround so data is captured while the pump runs.
  • Hardware Design and install valve/flow-diversion system — add solenoid or servo valves to redirect flow to "clean" output vs. recirculation line based on turbidity setpoint. Draft valve placement into housing CAD.
  • Integration Consolidate all components into one housing — route tubing, mount pump and electronics, seal filter cartridge, and label I/O ports. Perform leak test before sensor testing.
  • Sensor Source and integrate pH sensor — select a compatible analog/I2C pH probe, wire to Arduino, write firmware for reading + threshold logic, and include in final output monitoring.
